# Lendo pelo Mundo 

Esta é uma versão didática do projeto, construída principalmente com HTML5 e CSS3.

## Tecnologias

- HTML semântico;
- CSS responsivo;
- JavaScript simples apenas para busca, filtro, lista de leitura e formulário demonstrativo;
- `localStorage` para guardar os livros marcados.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.


## Escopo

Esta versão é um protótipo visual para apresentação do Projeto Integrador. A autenticação, a API, o banco de dados e o mapa real permanecem planejados para uma etapa posterior.
